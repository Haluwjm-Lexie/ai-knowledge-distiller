# AI 知识蒸馏助手 V1.1 · 安装与首次测试

这是按用户确认的 V1.1 正式规范封装的 **Codex Skill 候选包**。已做文件结构和基本规范检查，**尚未在你的本机 Codex 运行验证**。

## Windows 安装（不需要把 Skill 放进 Obsidian）

1. 下载 ZIP，解压，得到 `ai-knowledge-distiller-v1.1` 文件夹。确认该文件夹**直接**包含 `SKILL.md`。
2. 打开 Windows 文件资源管理器，在地址栏输入 `%USERPROFILE%\.codex\skills` 并按回车；如果你的 Codex 使用自定义 `CODEX_HOME`，使用该目录下的 `skills` 文件夹。
3. 将**整个** `ai-knowledge-distiller-v1.1` 文件夹复制进去。最终示例路径：`%USERPROFILE%\.codex\skills\ai-knowledge-distiller-v1.1\SKILL.md`。
4. 重新打开 Codex 或刷新 Skill 列表。在独立测试工作目录开启新会话，显式调用 `$ai-knowledge-distiller`。
5. 先执行 `evals/测试清单.md` 的 T01、T02、T03；检查真实暂停和用户确认流程。不要先把整个 Obsidian Vault 授权给 Skill。

## 第一次测试指令

```text
请使用 $ai-knowledge-distiller 处理这段人工构造资料：
“MCP 可以让 AI 连接 GitHub、飞书等工具。”
我早已知道这点，也没有得到操作步骤。
只执行阶段 0 和必要的阶段 A，先给我判断。不要生成阶段 B，不要修改任何文件。
```

然后回复：`无新增价值，跳过入库`。

**合格结果**：Skill 简短结束，不继续执行阶段 B，不生成知识笔记。
